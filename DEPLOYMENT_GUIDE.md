# GitHub & Railway Deployment Guide

## 🔗 Step-by-Step GitHub Setup

### 1. Create GitHub Repository

1. Go to [GitHub.com](https://github.com) and log in to your account
2. Click the **+** icon in the top right → **New repository**
3. Fill in the details:
   - **Repository name**: `team-task-manager`
   - **Description**: Team Task Manager - Full Stack Application
   - **Public/Private**: Choose based on preference
   - **DO NOT** initialize with README, .gitignore, or license (we already have these)
   - Click **Create repository**

### 2. Connect Local Repository to GitHub

After creating the repository, GitHub will show you commands. Run these in your terminal:

```bash
cd c:\Users\Lenovo\Desktop\ethara\team-task-manager

# Add remote repository (replace USERNAME with your GitHub username)
git remote add origin https://github.com/USERNAME/team-task-manager.git

# Rename branch to main (if not already main)
git branch -M main

# Push to GitHub
git push -u origin main
```

**Replace `USERNAME` with your actual GitHub username!**

### 3. Verify on GitHub

- Go to your repository: `https://github.com/USERNAME/team-task-manager`
- You should see all your files and folders
- The README should be displayed

## 🚀 Railway Deployment Guide

### 1. Create Railway Account

1. Go to [Railway.app](https://railway.app)
2. Click **Login**
3. Select **Sign up with GitHub**
4. Authorize Railway to access your GitHub account
5. Complete your profile setup

### 2. Deploy Backend Service

#### Step 1: Create New Project
1. On Railway dashboard, click **+ New Project**
2. Select **Deploy from GitHub repo**
3. Click **Configure GitHub App** (if first time)
4. Authorize Railway to access your repositories
5. Select your `team-task-manager` repository
6. Click **Deploy**

#### Step 2: Add PostgreSQL Database
1. In your Railway project, click **+ Add Service**
2. Select **Database** → **PostgreSQL**
3. Railway will automatically create the database

#### Step 3: Configure Environment Variables
1. Go to the **Backend** service (Node.js)
2. Click on the service → **Variables**
3. Add these variables:

```
DB_HOST=<PostgreSQL Host from database service>
DB_PORT=<PostgreSQL Port>
DB_NAME=<auto-generated by Railway>
DB_USER=<auto-generated by Railway>
DB_PASSWORD=<auto-generated by Railway>
JWT_SECRET=your-super-secret-key-change-this
NODE_ENV=production
PORT=5000
FRONTEND_URL=<your-frontend-url>
```

**To get database variables:**
- Click on the **PostgreSQL** service
- Go to **Variables** tab
- Copy: `DATABASE_URL`, `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`

#### Step 4: Add Start Command
1. In Backend service → **Settings**
2. Look for **Start Command**
3. Make sure it says: `node server.js`
4. Railway should auto-detect this

#### Step 5: Get Backend URL
1. Click on Backend service → **Settings**
2. Look for **Domains** section
3. Railway generates a public URL like: `https://team-task-manager-prod.up.railway.app`
4. Copy this URL (you'll need it for frontend)

### 3. Deploy Frontend Service

#### Step 1: Create Frontend Build
Your frontend needs to be built for production. Railway will handle this automatically.

#### Step 2: Add Frontend Service
1. In your Railway project, click **+ Add Service**
2. Select **GitHub** and your repository again
3. This time, specify the `frontend` directory:
   - Click **Settings** → look for **Root Directory**
   - Set to: `frontend`

#### Step 3: Configure Frontend Environment
1. In Frontend service → **Variables**, add:

```
REACT_APP_API_URL=<your-backend-url>
```

Replace `<your-backend-url>` with the URL from backend service (e.g., `https://team-task-manager-prod.up.railway.app/api`)

#### Step 4: Set Build and Start Commands
1. Frontend service → **Settings**
2. **Build Command**: `npm run build`
3. **Start Command**: `serve -s build` (or let Railway auto-detect)
4. Railway might need you to install `serve`:
   - Add to build: `npm install -g serve && npm run build`

#### Step 5: Get Frontend URL
1. Click on Frontend service → **Settings**
2. Copy the public URL like: `https://team-task-manager-frontend.up.railway.app`

### 4. Update Backend with Frontend URL (Optional)
If you deployed frontend on Railway:

1. Go back to Backend service
2. Click **Variables**
3. Update `FRONTEND_URL` to your frontend Railway URL
4. Save and Railway will redeploy

### 5. Test Your Deployment

1. Open your frontend URL in browser
2. Try signing up with a test account
3. Create a project and tasks
4. Check that everything works

## 🔄 Common Issues & Solutions

### Database Not Connecting
**Problem**: Connection refused error
**Solution**:
- Verify DATABASE_URL is correct
- Check if PostgreSQL service is running in Railway
- Restart services: Railway dashboard → Service → **Restart**

### CORS Error
**Problem**: Frontend can't connect to backend
**Solution**:
- Check `FRONTEND_URL` in backend environment variables
- Verify `REACT_APP_API_URL` in frontend variables
- Make sure URLs don't have trailing slashes

### Build Fails
**Problem**: Railway build fails
**Solution**:
- Check build logs in Railway dashboard
- Ensure package.json is in root of each service
- Verify Node version compatibility

### Deployment Stuck
**Problem**: Deployment never completes
**Solution**:
- Click **Restart** on the service
- Check service logs for errors
- Try redeploying from Railway dashboard
